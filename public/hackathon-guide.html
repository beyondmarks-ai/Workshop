Explain Astra with confidence.

A ready-to-use guide for presenting the product, the technology, and the Azure resources behind it in a hackathon.

One sentence

Astra helps students understand PDF learning material in their own language while keeping important English technical terms ready for exams.

Start here

Questions judges may ask

Use the short answer first. Add the second sentence only if they want more detail.

What problem does Astra solve?
Astra makes difficult study material easier to understand. A student can open a PDF, translate one page into a preferred language, listen to it, and ask questions about that page.
Who is Astra for?
It is designed for students who learn better in a regional language, while still needing English technical and exam terms for their answers.
What makes Astra different from a normal translator?
It translates page by page instead of processing the whole document at once. It also preserves important terms such as AI, model names, APIs, formulas, and exam concepts in English.
How does the main user flow work?
  1. The user uploads a PDF.
  2. Astra reads the selected page layout.
  3. It detects important English terms.
  4. It translates only that page and draws the result in the original positions.
  5. The user can save the translation, generate audio, or ask Astra about the open page.
What technologies did you use?
Next.js and React create the website. Node.js runs the custom server and WebSocket connection. Azure provides AI, document analysis, serverless functions, and storage. Sarvam AI provides Indian-language translation and voice features.
Why did you translate one page at a time?
It lowers waiting time and cost. The user sees the current page quickly, and the next page is processed only when they open or translate it.
How does Astra keep the original PDF layout?
Azure Document Intelligence finds each text block, its location, its size, and its role. Astra translates the text and draws it back inside matching coordinates on a canvas.
How does keyword preservation work?
Astra detects acronyms, formulas, product names, frameworks, APIs, and exam concepts. It sends them as glossary rules to the translation model. On first use, a concept can show its meaning followed by the English term; later uses keep the English term.
How does AI Ask work?
The user opens one PDF page and asks by voice or text. Speech is converted to text, only that page is analyzed, Azure OpenAI creates the answer, and Sarvam converts the answer back to audio. The answer can stream while it is being generated.
How does audio generation work?
A saved original or translated page is split into safe text chunks. Sarvam generates speech for each chunk, Astra joins the WAV files, saves each page, and can download a complete multi-page lesson.
How is user authentication implemented?
The user signs up with an email or phone number. Passwords are stored as salted scrypt hashes, never as plain text. A signed HttpOnly session cookie keeps the user signed in.
Where are uploaded files and users stored?
Azure Blob Storage stores documents in materials, page translations in translated, audio in audio, and user profiles in users.
How did you protect the API keys?
Permanent provider keys are stored in Azure Function App settings. The Next.js app only knows the Function URL and a revocable Function key. Keys are not placed in browser code or committed to GitHub.
Why use an Azure Function App?
It acts as a private gateway. The website asks the Function to call Azure OpenAI, Document Intelligence, Sarvam, or Storage. This keeps long-lived provider credentials away from the frontend and makes key rotation easier.
What would you improve next?
I would add per-user material access rules, rate limiting, email verification, password recovery, richer document formats, and monitoring dashboards for usage and latency.
What is the honest limitation of the demo?
The strongest experience is currently PDF-based. Translation quality depends on readable document text and the selected language model, so scanned or highly decorative pages may need OCR or manual review.

Live presentation

Three-minute demo script

Keep the demo focused on the user value, then explain the implementation.

  1. Open Astra: “Astra is a multilingual study assistant for PDF learning material.”
  2. Upload a PDF: choose English as the source and a regional language as the target.
  3. Show one page: point out that the original and translated pages stay aligned.
  4. Explain the key terms: show that words such as AI, APIs, formulas, and exam concepts remain in English.
  5. Open AI Ask: ask a question about the visible page in voice or text and show the streamed answer.
  6. Open Audio Lessons: generate or play the saved page audio.
  7. Close with security: “The permanent provider keys are inside Azure Function App settings, not in the browser or GitHub.”
